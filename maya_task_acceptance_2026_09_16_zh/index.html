    普通 Maya 任务完成链验收（2026-09-16）¶

    实现范围¶

    本轮目标：让模型选择操作，让统一执行层负责权限、命令/脚本、事务、恢复和验证。 已完成批准后冻结执行、通用操作与绑定规范分离、工具发现和结果投影收敛，以及小型 Maya 验收集。

    阶段提交：9faca3f1（批准执行）、27a0df2e（规范与路由分离）。最终收口提交包含本文件。

    验证层级¶

    • Python 3.7：227 项相关自动化检查通过，未执行全量回归。
    • Maya 2026 独立 mayapy：7/7 操作与批准案例通过，15/15 基线与恢复检查通过。
    • 真实 provider：当前配置为 Anthropic / claude-sonnet-5，启用分层模型；7 类任务均取得现场成功结果。
    • 交互 Maya 窗口、审批卡片点击和视觉蒙皮质量未在本轮验收。独立临时场景不等于用户生产场景。

    验收中发现并修正的问题¶

    1. 配置关闭预取仍查询三个节点连接图：修正为遵守配置。
    2. 已验证写入的回复阶段仍隐式查询：写操作回复使用已有回执。
    3. value 未声明类型、模型把 5 传成字符串：补齐 JSON 类型与示例，保留宿主严格检查与明确报错。
    4. 后续成功仍被早先未执行状态覆盖：同命令、同目标成功回执可解除未执行尝试，未知/实际失败保留。
    5. 批量工具抹去子命令名称：结果投影保留子回执实际命令身份。
    6. 进程内 Maya 查询被送入线程池：并行仅对显式支持安全桥接的执行器开启。
    7. 批准后的选择可能变化：批准前展开 @selection，冻结完整节点参数，确认不读取新选择。

    属性修复后真实模型直接提交 JSON 数字 5，一次写入成功，无需脚本或批准。 此前失败记录保留，未用最后的成功覆盖验收历史。

    当前结论与界限¶

    本轮四步工程目标已完成。测试支持小型普通任务的完成链和恢复机制，不是任意绑定项目 自动成功的承诺。真实 provider 仍会额外读取或产生较长说明；样本耗时约 14–34 秒， 不能宣称所有任务都足够快。下一轮应观察真实任务的多余调用、错误参数和回答长度， 无需继续扩建自定义推理/记忆系统。
